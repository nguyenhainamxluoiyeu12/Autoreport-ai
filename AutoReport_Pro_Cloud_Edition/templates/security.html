SECURITY

Cấu hình bảo mật cao

Hệ thống đã thêm các lớp bảo vệ cơ bản để giảm spam, report tự động và tấn công web phổ biến.

OAuth an toàn

Google/Facebook dùng Client ID/Secret qua biến môi trường, không hard-code trong code.

CSRF Token

Form POST có token chống gửi giả mạo từ website ngoài.

Rate Limit

Giới hạn {{ rate }} request/phút trên session để giảm spam/bot.

Login Protection

Khóa tạm khi nhập sai nhiều lần và ghi SecurityLog.

Security Headers

X-Frame-Options, CSP, nosniff, Referrer Policy và Permissions Policy.

Lọc input

Xóa tag HTML nguy hiểm, giới hạn độ dài nội dung hỗ trợ/chat.

Để bảo mật production tốt hơn: bật HTTPS, đặt SECRET_KEY mạnh, COOKIE_SECURE=1, dùng PostgreSQL, cấu hình domain OAuth chính xác, sao lưu database và không commit file .env.
